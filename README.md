# מי הגנב? (Windows Detective Game)

משחק בלשים שיתופי לדפדפן, לעד 4 שחקנים ממחשבים שונים.

## איך מריצים

1. ודאו שמותקן Node.js (גרסה 18 ומעלה).
2. בתיקיית הפרויקט:
   ```
   npm install
   npm start
   ```
3. השרת עולה על `http://localhost:3000`.
4. כל שחקן פותח את הכתובת בדפדפן שלו (אם משחקים מכמה מחשבים באותה
   רשת - צריך את כתובת ה-IP של המחשב שמריץ את השרת, למשל
   `http://192.168.1.50:3000`, ולא `localhost`).
5. שחקן אחד לוחץ "צור חדר" ומקבל קוד בן 4 אותיות, ושאר השחקנים
   מצטרפים עם אותו קוד.
6. המארח לוחץ "התחל משחק".

## מבנה הקוד

- `server/gameEngine.js` - כל חוקי המשחק (לוח, קוביות, חשודים, רמזים,
  תנאי ניצחון/הפסד). לוגיקה טהורה, בלי רשת - קל לבדוק ולשנות.
- `server/rooms.js` - ניהול חדרים (יצירה/הצטרפות, עד 4 שחקנים).
- `server/index.js` - שרת Express + Socket.io שמחבר הכל יחד ומשדר
  עדכוני מצב לכל השחקנים בזמן אמת.
- `public/` - הלקוח (מה שרואים בדפדפן): `index.html`, `style.css`,
  `game.js`.

## מה כבר ממומש

- לוח 20x20, הבלשים מתחילים במרכז.
- רמזים (עקבות) בפריסה קבועה סביב המרכז; החפץ שכל רמז מייצג מוגרל
  מחדש בכל משחק.
- מסלול השועל ממוזג לתוך אותו לוח (על ההיקף שלו).
- 3 קוביות עם עין/עקבות (1-3 צעדים), עד 3 הטלות עם אפשרות נעילת קוביות.
- הצלחה בעקבות = תנועה; הצלחה בחשודים = משיכת 3/2/1 קלפים לפי הניסיון
  שהצליח בו.
- שריפת חשודים אוטומטית מול הרמזים שנחשפו.
- ניצחון כשנשאר חשוד אחד בלבד והקופה ריקה; הפסד כשהשועל עובר 50 צעדים.

## מה עוד אפשר להוסיף (בהמשך)

- מסחר ברמזים בין שחקנים.
- גרפיקה מותאמת ללוח, לקוביות ולדמויות (כרגע צורות פשוטות).
- אפשרות "התחלה מחדש" בלי לרענן דף.
